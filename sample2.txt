For a real-time classroom system, here's the approach:

**The Flow:**
```
Student joins classroom → WebSocket connection established → 
All members in that classroom receive real-time updates
```

---

**1. Connection Manager (handles all active WebSocket connections):**

```python
# websocket/manager.py

from fastapi import WebSocket
from typing import dict

class ConnectionManager:
    def __init__(self):
        # Store connections per classroom {classroom_id: [websocket1, websocket2]}
        self.active_connections: dict[int, list[WebSocket]] = {}
    
    async def connect(self, websocket: WebSocket, classroom_id: int):
        await websocket.accept()
        if classroom_id not in self.active_connections:
            self.active_connections[classroom_id] = []
        self.active_connections[classroom_id].append(websocket)
    
    def disconnect(self, websocket: WebSocket, classroom_id: int):
        self.active_connections[classroom_id].remove(websocket)
    
    async def broadcast(self, message: str, classroom_id: int):
        """Send message to all members in a classroom"""
        if classroom_id in self.active_connections:
            for connection in self.active_connections[classroom_id]:
                await connection.send_text(message)

manager = ConnectionManager()
```

---

**2. WebSocket Route:**

```python
# routes/classroom/classroom.py

from fastapi import WebSocket, WebSocketDisconnect

@router.websocket("/classroom/{classroom_id}/ws")
async def classroom_websocket(
    websocket: WebSocket,
    classroom_id: int,
    token: str,  # pass token as query param
    db: Session = Depends(get_db)
):
    # 1. Validate token & get user
    user_id = await get_current_user(token, db)
    
    # 2. Check user is actually a member of this classroom
    is_member = db.query(GroupMembers).filter(
        GroupMembers.user_id == user_id,
        GroupMembers.group_id == classroom_id
    ).first()
    if not is_member:
        await websocket.close(code=403)
        return
    
    # 3. Connect
    await manager.connect(websocket, classroom_id)
    await manager.broadcast(f"User {user_id} joined the classroom", classroom_id)
    
    try:
        while True:
            # 4. Receive messages and broadcast to all
            data = await websocket.receive_text()
            await manager.broadcast(f"User {user_id}: {data}", classroom_id)
    
    except WebSocketDisconnect:
        manager.disconnect(websocket, classroom_id)
        await manager.broadcast(f"User {user_id} left the classroom", classroom_id)
```

```
- Teacher starts/stops exam notifications
- Student submission alerts
- Live participant list
- Teacher broadcasts questions
```
